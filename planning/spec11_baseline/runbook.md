# spec11_baseline — Runbook

## Usage
1. Start the Streamlit application:
   ```bash
   streamlit run app.py
   ```
2. Below the header, locate the **Select Evaluation Mode** radio button.
3. Switch between **Agentic RAG** and **Baseline LLM**.
4. Enter identical queries in both modes to compare depth, factual accuracy, and recency of the generated reports.
