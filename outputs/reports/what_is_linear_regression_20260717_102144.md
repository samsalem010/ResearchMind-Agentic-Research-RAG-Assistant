**Summary:** Linear regression is a fundamental statistical and machine learning technique that models the relationship between a dependent variable and one or more independent variables by fitting a straight line to observed data. It assumes a linear relationship between variables and uses the equation $Y = aX + b$ to describe this connection. The goal is to find the best-fit line that minimizes the difference between predicted values and actual data points.
